# Blog de Finanças

Blog institucional sobre educação financeira, desenvolvido como Atividade Online Pontuada 02 (AOP2) da disciplina de Programação Web - Front End.

## Tema

Finanças

## Páginas

| Página | Arquivo | Descrição |
|---|---|---|
| Home | `index.html` | Apresentação do blog e conteúdos em destaque |
| Orçamento | `conteudo_1.html` | Orçamento pessoal e a regra 50-30-20 |
| Reserva | `conteudo_2.html` | Reserva de emergência |
| Investimentos | `conteudo_3.html` | Conceitos básicos para iniciantes |
| Glossário | `glossario.html` | Termos financeiros explicados |
| Sobre | `sobre.html` | Propósito do blog |
| Contatos | `contatos.html` | Formulário de contato |

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox e media queries para responsividade)

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` em qualquer navegador.

Não é necessário instalar nada.

## Site publicado

Disponível em: https://SEU-USUARIO.github.io/blog-financas/

## Aviso

Os conteúdos têm caráter educacional e não substituem a orientação de um profissional certificado.
